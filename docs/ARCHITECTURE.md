# Архитектура Lizon

## Границы

```
apps/web          кабинеты, плеер активностей, редактор вопросов
apps/api          NestJS: auth, RBAC, курсы, банк, попытки, задания, файлы, сертификаты
packages/shared   правила доступа, формулы, плагины вопросов, импорт/экспорт
```

Веб не хранит правильные ответы. Для урока API отдаёт студенту виджет без ключа (`presentContent`). Мини-квиз урока проверяется `POST /api/activities/:id/practice`. Попытка теста хранит снимок вопроса: правка банка не меняет уже начатую попытку.

## Сущности

Пользователь связан с ролями многие-ко-многим. У роли набор прав (`courses.read`, `content.author`, `questions.manage`, `quizzes.grade`, …). Запись на курс (`Enrollment`) задаёт роль внутри курса и хранит прогресс и итоговую долю.

Курс содержит модули, модуль — активности. У активности тип, окно `openAt` / `dueAt` / `closeAt`, JSON условия доступа и правило завершения (`view`, `submit`, `pass`). Каждое сохранение материала пишет `ContentVersion`; восстановление создаёт новую версию, историю не переписывает.

Тест — слоты. Слот ссылается на вопрос или на правило случайной выборки (категория, теги, типы, число). На попытке правило разыгрывается заново, как случайный вопрос в Moodle. «Вариант экзамена» — отдельный тест: тот же состав, но случайные слоты разыграны один раз и записаны фиксированными вопросами. Попытка содержит `AttemptQuestion`: тип, текст, материализованное определение, датасет вычисляемого вопроса, ответ, балл.

Задание и сдача живут отдельно от теста. Журнал `Grade` сводит тест и задание к одной строке на активность. Сертификат выпускается, когда все активности завершены, незакрытых проверок нет и итог курса не ниже `passingGrade`.

Группа курса нужна условию «только эта группа». Обсуждение — плоский тред с `parentId`. Уведомления и предпочтения каналов (кабинет / почта) — на пользователя. `CustomFieldDefinition` и `Setting` — метаданные и флаги платформы, в том числе `allowRegistration`.

## Доступ

`evaluateAccess` в `@lizon/shared` разбирает дерево условий `date | completion | grade | group | all | any`. Преподаватель курса и носитель `courses.manage` ограничения не видят. Срок `dueAt` сдачу не закрывает: опоздание помечается. Закрывает `closeAt`.

Просмотр урока с правилом `view` завершает активность при открытии. Тест завершается сдачей или, если правило `pass`, при доле не ниже порога. Итог теста в журнале: лучшая, средняя, первая или последняя попытка.

## Плагин вопроса

Авторское определение и снимок попытки — разные JSON.

- Авторское: пары соответствия с общими id, все датасеты вычисляемого вопроса, доли баллов.
- `materialize` перемешивает варианты, подставляет один датасет, выдаёт непрозрачные id вариантов. Для соответствия правильная связь хранится как `correctStemId` и вырезается из `publicView`.
- `grade` возвращает долю 0..1, текст обратной связи и флаг ручной проверки. Штраф адаптивного режима: верный ответ после n ошибок даёт `max(0, 1 − penalty·n)`; до сдачи неверный ответ увеличивает счётчик и показывает 0.

Режимы обратной связи: `immediate` (сразу и блокировка), `deferred` (после сдачи), `closed` (после `closeAt` активности), `adaptive` (повтор со штрафом). Описание всегда с нулевым баллом. Пустое эссе — 0, непустое ждёт преподавателя.

Формулы: числа, `+ − * / ^`, скобки, `{переменная}`, функции `abs`, `sqrt`, `min`, `max`, `round`. Шаблоны пропусков — `[[id]]`, чтобы не пересечься с переменными. Маска короткого ответа — свой разбор `*` и `?`, не регулярное выражение.

Импорт Moodle XML пропускает неизвестный тип с предупреждением. Cloze читает синтаксис `{вес:ТИП:...}`.

## Безопасность

- Access-cookie `lizon_access` на 15 минут, refresh `lizon_refresh` на 30 дней. В базе хранится только SHA-256 refresh, при обновлении сессии он меняется.
- Мутации требуют заголовок `x-requested-with: lizon`.
- Лимит: 10 запросов в минуту на вход и 300 на остальные маршруты с одного IP. В `NODE_ENV=test` лимит выключен.
- HTML урока чистится при сохранении. Markdown на клиенте без сырого HTML. Видео — только YouTube, Vimeo, прямой файл или файл платформы.
- Загрузка: allowlist MIME, без svg/html/js, до 20 МБ. Локальный драйвер не отдаёт путь вне каталога загрузок.

## Масштабирование

API без состояния сессии в памяти: JWT и база. Локальный диск файлов нужно сменить на S3, если реплик больше одной. Redis общий для лимитов. Горизонтально поднимаются реплики API за одним origin веб-приложения.
